# Portfólio de Python para Dados

Este repositório registra minha evolução em Python com foco em dados. Cada projeto nasce de um problema prático e documenta os conceitos que aprendi durante a construção.

## Projetos

| Nº | Projeto | Conceitos principais | Situação |
|---:|---|---|---|
| 1 | [Analisador de faturamento](projetos/01-analisador-faturamento/) | variáveis, entrada de dados, `float`, formatação, `if`, `else` e `and` | Concluído |
| 2 | Classificador de desempenho de vendas | `elif`, comparações e ordem das condições | Próximo |
| 3 | Resumo de vendas de vários dias | listas e funções numéricas básicas | Planejado |
| 4 | Leitor diário de vendas | repetição com `for` | Planejado |
| 5 | Controle de despesas por categoria | dicionários | Planejado |
| 6 | Calculadora de indicadores | funções, parâmetros e retorno | Planejado |
| 7 | Importador de vendas em CSV | arquivos e módulo `csv` | Planejado |
| 8 | Limpador de dados de vendas | validação e tratamento de erros | Planejado |
| 9 | Análise tabular com pandas | DataFrame, filtros e agrupamentos | Planejado |
| 10 | Relatório visual de desempenho | pandas, matplotlib e integração | Planejado |

## Método de estudo

Primeiro compreendo o conceito e depois tento implementar sozinho. Quando encontro dificuldades, trabalho com perguntas e dicas graduais, analisando cada erro antes de corrigir o código.

## Ambiente

- Python 3.13
- Visual Studio Code
- Extensão oficial do Python
