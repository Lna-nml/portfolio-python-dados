## Como executar

1. Tenha o Python 3 instalado.
2. Clone este repositório.
3. Acesse a pasta do projeto desejado.
4. Execute o arquivo `.py` pelo terminal ou pelo Visual Studio Code.

Exemplo:

```bash
python projetos/01-analisador-faturamento/analisador_faturamento.py
```

## Método de estudo

Primeiro estudo o conceito e depois tento implementá-lo sozinho. Quando encontro dificuldades, analiso cada erro, busco entender a causa e aplico a correção. Cada projeto inclui documentação sobre o problema resolvido e os conceitos utilizados.
